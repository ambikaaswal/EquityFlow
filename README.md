EquityFlow - ML-Powered Stock Investment Platform

An intelligent stock investment platform that combines traditional investing with machine learning-assisted portfolio analysis. Users can invest manually or allocate up to 30% of their available balance to an automated investment strategy powered by price prediction and financial sentiment analysis.

The project follows a microservice architecture consisting of two React applications, a Node.js/Express backend, and a Python ML service.

Features
User authentication
Manual stock investing
ML-assisted automated investing
Portfolio dashboard
Watchlist management
Transaction history
Live market data
Background model retraining via Cron jobs
RESTful API architecture
ML-Assisted Investing

Users may allocate up to 30% of their available balance to the automated investment strategy.

Investment confidence is generated by combining:

Random Forest price prediction trained on historical market data
FinBERT financial news sentiment analysis
Weighted confidence scoring

The resulting confidence score is stored in MongoDB and consumed by the backend to provide automated investment decisions and portfolio analysis.

Machine Learning Pipeline

The Python ML service is responsible for:

Fetching historical stock market data
Feature engineering
Training Random Forest models
Running FinBERT sentiment analysis on financial news
Combining prediction confidence with sentiment score
Saving confidence scores to MongoDB
Periodic retraining using Cron jobs
