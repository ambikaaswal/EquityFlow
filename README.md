EquityFlow - AI Powered Stock Investment Platform

An intelligent stock investment platform that combines traditional investing with AI-assisted portfolio management. Users can invest manually or allow the platform to automatically manage up to 30% of their available balance using machine learning and financial sentiment analysis.

The project is built as a microservice architecture consisting of two React applications, a Node.js backend, and a Python ML service.

Features

Manual stock investing
AI-assisted automated investing
Portfolio dashboard
Watchlist management
Transaction history

Automated portfolio updates
Background scheduled model updates
RESTful API architecture
AI Assisted Investing

Users may allocate up to 30% of their available balance to automated investing.

Investment decisions are generated by combining:

Random Forest price prediction model trained on historical stock data
FinBERT financial news sentiment analysis
Weighted confidence scoring
Automated portfolio updates

The generated confidence score is stored in MongoDB and consumed by the backend to provide investment recommendations.

Machine Learning Pipeline

The ML microservice is responsible for:

Fetching historical market data
Feature engineering
Training Random Forest models
Running FinBERT sentiment analysis on financial news
Combining prediction confidence with sentiment score
Saving AI recommendations to MongoDB
Periodic retraining using Cron jobs
